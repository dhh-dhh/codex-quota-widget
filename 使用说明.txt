Codex 额度小组件

双击“启动额度小组件.vbs”或桌面快捷方式打开。
拖动窗口顶部可以移动位置；默认置顶，每 60 秒刷新一次。
勾选“开机启动”即可随 Windows 登录启动，取消勾选即可关闭自启动。
右侧“深色模式”可切换为黑灰主题，重启后恢复上次选择。
点右上角 × 退出。重复启动不会出现多个窗口。

读取 Codex 当前登录账户的额度，不需要填写 API Key，不发起模型对话。
额度来自官方 app-server 的 account/rateLimits/read 只读接口。
https://learn.chatgpt.com/docs/app-server
多种额度窗口会分别显示；剩余百分比 = 100 - 已用百分比。
断网或登录失效时显示错误提示，并保留上次成功的数据。重置时间使用电脑本地时区。

依赖已安装的 Codex 和本机自带的 Node 运行环境。若卸载 Codex 或清理其运行环境，需重新配置。

支持显示显卡、内存占用，约每 2 秒刷新；显卡读取需要 NVIDIA 驱动。
将 HTTPS Clash 订阅链接保存为项目根目录 subscription.local.txt，可显示订阅流量。
已有 providers.local.json 时，需要加入 traffic 服务商；详细步骤见 PROVIDERS.md。
订阅链接和 appearance.json 主题偏好仅保存在本机，不要公开上传。
升级时请更新整个源码目录，尤其是 widget-ui.ps1 及 providers 文件夹，同时保留本机私有配置。

v1.4 在流量卡片内合并了“系统代理”开关。Clash Verge 需保持运行，代理状态约每 2 秒同步。
此开关修改 Windows 手动代理状态，不更改 Clash 应用内部偏好；Clash 重新应用配置时可能接管系统代理。
其他代理、PAC 或代理守卫启用时不允许切换，并显示原因。升级请一并复制 proxy-control.ps1。
